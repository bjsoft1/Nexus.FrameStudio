# Nexus.FrameStudio — 20 + 20 review points

**Design coverage, not a claim of completed native functionality.** The HTML prototype implements UI interactions and JSON/SRT downloads. Device capture, composed video export and portable media packaging are future native work.

2. Browse assets and relink missing source files. (Screens 05, 28.)
3. Edit screen, webcam, visuals, audio and effects on separate tracks. (Screens 27.)
4. Trim clip starts and ends without changing originals. (Screens 29.)
5. Split clips at the playhead and remove unwanted sections. (Screens 29.)
6. Join multiple clips and rearrange their order. (Screens 30.)

8. Resize video and reduce bitrate or output quality. (Screens 32.)
9. Add text titles, labels and lower thirds. (Screens 33.)

11. Add rectangles, circles, arrows, lines and highlights. (Screens 35.)
12. Place images and logos over the main video. (Screens 36.)
13. Place video and webcam picture-in-picture overlays. (Screens 37.)

## Approval boundary

Review the UI first. The five implementation-phase task files have deliberately **not** been created. After approval, each phase must identify tasks, dependencies, manual and automatic test cases, exact UI steps, expected results, evidence, remaining work and an explicit approval gate.
